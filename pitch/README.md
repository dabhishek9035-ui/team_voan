# Pitch presentation

Open `index.html` in a browser. Use the left/right arrow keys, Page Up/Page Down or the on-screen controls to move through eight slides. The fullscreen control starts presentation mode. The deck is HTML so it can be edited directly without a slide package or external assets.

All screenshots on slides are hand-authored synthetic fixtures and are labelled as such. The deck includes no coordinator quotes, real-world results or unmeasured product claims. The talk track and judge Q&A are in the [demo script](../docs/demo_script.md).
